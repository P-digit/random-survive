# 🎲 랜덤 좌표 생존기

> 지구 어딘가의 랜덤 좌표에 떨어져, 기본 물품만 가지고 **한국으로 돌아오는** AI 텍스트 생존 게임

떨어진 곳의 **실제 날씨와 기후**를 바탕으로 AI 게임 마스터가 상황을 만들어 냅니다. 플레이어는 챗봇과
대화하듯 행동을 입력하며 살아남고, 사람이 사는 곳을 찾고, 돈을 벌고, 한국 공관의 도움을 받아
서울까지 돌아와야 합니다.

NVIDIA AI Campus 기초 과정(머신러닝, LLM, 멀티모달)에서 배운 내용을 활용한 개인 프로젝트입니다.

## 한 판의 흐름

1. **낙하** – 사막, 툰드라, 열대우림 같은 낯선 곳에서 정신을 차립니다. 가진 것은 물 한 병, 에너지바, 라이터, 칼, 여권, 배터리가 얼마 남지 않은 스마트폰, 그리고 $50뿐입니다.
2. **생존** – 물·식량·체온을 챙기며 버팁니다. 시간이 흐를수록 배고프고 목마르고 지치며, 밤에는 추워집니다.
3. **사람 찾기** – 엔진 소리, 연기, 불빛 같은 단서를 따라가 도로·마을·유목민 천막을 찾습니다.
4. **도움 받기** – 마을과 도시에서 일하고, 거래하고, 차를 얻어 탑니다. 한국 공관(대사관·총영사관)과 연락이 닿으면 여행증명서와 지원금을 받을 수 있습니다.
5. **귀환** – 공항에서 한국행 비행기를 타거나, 배·기차·버스를 갈아타며 서울 반경 60km 안에 들어오면 승리입니다. 체력이 0이 되면 패배입니다.

## 주요 기능

### 실제 세계를 바탕으로 한 무대
- **랜덤 낙하** – 지구 표면에서 고르게 좌표를 뽑고, 바다는 걸러 육지에만 떨어집니다.
- **실제 날씨** – 그 좌표의 현재 날씨와 16일치 시간별 예보를 게임 시계에 맞춰 적용합니다. 밤에는 기온이 내려가고 낮에는 오릅니다. 시계는 지금 있는 곳의 현지 시각을 따릅니다.
- **실제 기후** – 최근 1년간의 기온·강수량 기록으로 기후대(사막, 열대우림, 냉대 등 8종)와 지금 계절(열대는 우기·건기)을 판별해 지형, 서술, 그림에 반영합니다.
- **실제 도시** – 이동 이벤트는 실제 지도 위의 가까운 도시(248곳), 마을, 한국 공관, 국제공항으로 데려갑니다.

### AI 게임 마스터
- **자유 입력** – 정해진 선택지 없이 하고 싶은 행동을 문장으로 입력합니다. 추천 행동 3개도 함께 제시됩니다.
- **숫자는 엔진이, 이야기는 LLM이** – LLM은 체력·돈·위치를 직접 바꾸지 못하고, 툴 호출(Function Calling)로 엔진에 요청만 합니다. 엔진이 규칙을 검사하고 변화 폭을 제한합니다.
- **이야기의 개연성** – "멀리서 엔진 소리가 들린다" 같은 단서가 생기는 순간, 엔진이 그 정체(도로, 마을, 유목민 천막, 벌목장 등)와 방향·거리를 지형에 맞게 미리 정해 둡니다. 따라가면 그것이 반드시 나타나고, 도착 시각에 따라 모습이 다릅니다(밤의 마을은 잠들어 있고, 밤의 도로엔 차가 드뭅니다). 약속·인물·장소 같은 확정된 사실도 기록해 매 턴 게임 마스터에게 전달합니다.
- **서술·그림·위치의 일치** – 이동은 플레이어가 그 이동을 말했을 때만 일어나고, 도착지의 장소 유형은 규칙으로 정해집니다. 장소가 바뀐 턴에 서술이 옛 장소에 머물면 새 장소에 맞게 다시 씁니다. 그래도 이동 없이 위치가 바뀌면 안전장치가 원래대로 되돌립니다.
- **억지 방지** – 플레이어의 입력은 '시도'일 뿐 '사실'이 아닙니다. "텔레포트기를 줍는다"처럼 현실에 없거나 그 자리에 있을 수 없는 것은 실패합니다.
- **자유 행동** – 위험하거나 불법인 행동(싸움, 절도, 차량 탈취, 무단 침입 등)도 막지 않습니다. 대신 엔진이 성공 확률을 계산해 판정하고, 실패하면 다치거나 붙잡힙니다.
- **한국어 서술** – 서술에 다른 언어 문자가 섞이면 한국어로 다시 쓰게 하고, 그래도 남으면 지웁니다.

### 게임 시스템
- **극한 지형** – 설원·사막·고산·열대우림에서는 소모와 피해가 커지고, 불과 쉘터가 생사를 가릅니다.
- **상황에 맞는 이벤트** – 돌발 이벤트 178개(긍정 94개, 위험 64개)가 장소·지형·밤낮·날씨·기온·실내외·계절 조건을 가집니다. 야생에서는 동물과 자연이, 마을·도시에서는 사람이 이벤트의 중심입니다.
- **위험이 따르는 기회** – 장거리 트럭, 구조 헬기, 한국인의 초대, 공관의 도움, 한국 쪽으로 가는 화물선 같은 큰 기회가 가끔 찾아옵니다. 받아들이면 20~30% 확률로 강도, 사기, 폭풍 같은 나쁜 결과가 됩니다.
- **ML 위험도 예측** – 날씨와 몸 상태로 위험 등급(안전/주의/위험)을 예측합니다. 등급이 높을수록 이벤트가 자주, 그리고 나쁘게 일어납니다.
- **생존 지식 RAG** – 뱀에 물렸을 때, 저체온증, 여권 분실 같은 생존 지식 문서를 검색해, 올바른 대처에는 좋은 결과를 줍니다.
- **교통편 예약** – 표를 미리 사 두면 몇 턴이 지나도 기억했다가, 탈 때 요금 없이 탑승합니다.
- **수배도** – 현실에서 범죄인 행동을 누군가 목격했을 때만 오릅니다. 수배 중이면 경찰이 다가오고 공항·항구에서 붙잡힐 수 있습니다.
- **자동 저장과 이어하기** – 매 턴 저장되어, 프로그램을 껐다 켜도 이어서 할 수 있습니다.

### 화면
- **장면 이미지** – 위치·기후·계절·날씨·시간대에 맞는 장면을 그립니다. 오두막에 들어가거나 마을에 도착하는 등 장면이 바뀌면 새로 그립니다.
- **같은 장소는 같은 모습으로** – 같은 곳에 머무는 동안 낮밤이나 날씨가 바뀌면, 새로 그리지 않고 이전 그림을 편집(Images API edit)해 빛과 날씨만 바꿉니다. 편집한 그림도 Vision으로 다시 읽어, 장면에 없던 건물·불빛이 생겼으면 한 번 더 고치고 그래도 생기면 편집본을 버립니다(이전 그림 유지). 실내는 다시 그리지 않습니다. 장면 묘사와 등장인물(이름·역할·생김새)도 기록해 두어, 같은 곳의 구성과 사람이 바뀌지 않습니다.
- **현지 언어의 표지판** – 그림 지시문에는 한글을 넣지 않고 영어 지명을 씁니다(한글이 섞이면 이미지 모델이 표지판에 뜻 없는 한글을 그려 넣기 때문). 표지판·간판이 나온다면 그 나라 언어로 쓰도록 지정합니다(오스트레일리아는 영어, 몽골은 키릴 문자 몽골어 등 151개국).
- **그림과 서술의 일치** – 게임 마스터가 밝힌 대상만 그리게 하고, 그려진 그림을 다시 Vision으로 읽어 "화면에 보이는 것"을 게임 마스터에게 알려 줍니다. 그림에 보이는 건물은 게임에서도 존재합니다.
- **상태창(HUD)** – 시각·날씨, 한국까지 남은 거리, 체력·포만감·수분·기력, ML 위험도, 소지품, 단서, 탈것·수배도, 교통 요금표를 보여 줍니다. 수치가 변하면 초록(+)·빨강(-)으로 표시됩니다.
- **중요 알림** – 기회, 위험, 단서 발견, 이동, 판정 결과, 체포, 사망·귀환은 대화창에 색이 다른 상자로 표시됩니다.

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
git clone https://github.com/P-digit/random-survive.git
cd random-survive

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # Windows: copy .env.example .env
# .env 파일을 열어 OPENAI_API_KEY=sk-... 로 실제 키를 입력 (따옴표 없이)

python app.py
```

터미널에 표시되는 주소(기본 `http://127.0.0.1:7860`)를 브라우저로 열고 **🎲 낙하 시작**을 누르면 됩니다.

- 처음 실행할 때 위험도 모델을 몇 초 동안 학습합니다.
- 장면 이미지는 한 장에 10~30초가 걸리고 요금이 듭니다. 화면의 체크박스로 끌 수 있습니다.
- `chromadb`는 설치가 오래 걸려 선택 패키지로 분리했습니다. 없으면 같은 임베딩을 numpy로 비교하는 방식으로 RAG가 동작합니다.

### 다른 사람에게 보여 주기 (시연용 공유 링크)

```bash
python app.py --share
```

터미널에 `https://xxxxx.gradio.live` 형태의 공개 주소가 표시됩니다. 이 주소를 받은 사람은 아무것도 설치하지 않고
브라우저로 접속해 플레이할 수 있습니다.

- 게임은 실행한 컴퓨터에서 돌아갑니다. 프로그램을 끄거나 컴퓨터가 잠들면 접속이 끊깁니다.
- 링크는 임시입니다. 다시 실행하면 주소가 바뀝니다.
- 접속자 모두가 실행한 컴퓨터의 OpenAI 키를 사용합니다.
- 공유 모드에서는 자동 저장과 이어하기가 꺼집니다(접속자들이 저장 파일 하나를 함께 쓰게 되기 때문). 접속자마다 게임은 따로 진행됩니다.

## 플레이 방법

입력창에 하고 싶은 행동을 자유롭게 쓰거나, 추천 행동 버튼을 누릅니다. 예를 들면:

- `주변을 살펴본다`, `물을 찾는다`, `마른 나뭇가지로 불을 피운다`, `바위 틈에서 7시간 잔다`
- `엔진 소리 쪽으로 간다` – 상태창 **CLUES**에 있는 단서를 따라갑니다.
- `마을에서 일자리를 구한다`, `생수 두 병을 산다`, `버스표를 산다`
- `가장 가까운 마을로 간다`, `도시로 간다`, `계속 간다` – 한 턴에 다 못 가는 거리는 여러 턴에 걸쳐 갑니다.
- `한국 대사관에 간다`, `귀국 지원을 요청한다`, `공항으로 간다`, `한국행 비행기에 탑승한다`
- `트럭 기사를 기절시키고 트럭을 빼앗는다` – 엔진이 성공 확률을 계산해 판정합니다.

한 턴에는 행동 하나만 처리됩니다. 결과가 나오면 다음 행동을 정하면 됩니다.

## 게임 규칙

### 기본

| 항목 | 내용 |
|---|---|
| 시작 물품 | 물 1L, 에너지바 2개, 라이터, 다용도 칼, 여권, 스마트폰(배터리 30%), $50 |
| 승리 | 서울 반경 60km 안에 도착 |
| 패배 | 체력 0 |
| 턴 | 한 턴에 행동 하나. 이동과 시간 경과는 한 턴에 한 번만 반영됩니다 |
| 장소 | 야생 → 마을 → 도시. 장소 유형은 엔진만 바꾸며, 주사위가 아니라 규칙으로 정합니다: 걷기·운전 → 야생(실제 도시 15km 이내면 도시), 버스·히치하이킹 → 마을(도시 30km 이내면 도시), 기차·배·비행기 → 도시. 걷다가 우연히 마을에 닿는 일은 없고, 마을은 "마을로 간다"나 단서로 찾아갑니다 |
| 이동의 조건 | 모든 이동(장거리 이동, 목적지로 가기, 단서 따라가기, 기회 수락)은 플레이어가 그 이동을 말했을 때만 일어납니다. "쉴 곳을 찾는다", "나무 아래로 옮긴다"처럼 그 자리 근처에서 움직이는 행동은 장면만 바뀌고 장소는 그대로입니다. 5km 미만의 도보는 이동으로 치지 않습니다 |
| 초반 | 시작 후 36시간 동안은 도시·공항·공관으로 갈 수 없고, 한 번에 60km까지만 이동합니다. 낙하 지점 근처(야생과 마을)에서 버티며 길과 사람, 여비를 찾는 시기입니다 |
| 저장 | 매 턴 자동 저장. 사망하거나 귀환하면 저장 파일이 지워지고, "새로 낙하"를 누르면 이전 저장을 덮어씁니다 |

### 시간과 몸 상태

| 항목 | 내용 |
|---|---|
| 시간 | 모든 행동에 시간이 흐릅니다(대화 15~30분, 물 찾기 1~3시간, 일하기 4~8시간, 취침 6~8시간). 게임 마스터가 시간을 빠뜨리면 엔진이 입력 문장에서 추정합니다 |
| 소모 | 포만감·수분·기력이 시간에 따라 줄고(기본 속도의 1.6배, `survival/config.py`의 `VITALS_DRAIN`), 0이 되면 체력이 깎입니다. 잘 먹고 쉬면 체력이 회복됩니다 |
| 날씨 | 야생에서 체감 0°C 이하 또는 35°C 이상이면 시간당 체력이 깎이고, 극단적일수록 더 크게 깎입니다. 실내에 있거나 불·쉘터가 있으면 피해가 1/4로 줄어듭니다 |
| 소지품 | 들고 다닐 수 있는 물건만 들어갑니다. 오두막·오아시스 같은 장소와, 차·트럭·오토바이·보트·낙타 같은 탈것은 거부됩니다(탈것은 따로 '보유 탈것'이 됩니다). 먹거나 마시거나 쓴 것은 사라지고, `에너지바 2개`는 하나씩 줄어듭니다 |
| 먹고 마시기 | 소지품을 먹거나 마시면 종류별 기본 회복량(물 1L 수분 +45, 생수 +35, 에너지바 포만감 +25, 비상식량 +40 등, `config.py`의 `CONSUMABLES`)이 보장되고 15분만 흐릅니다. GM이 적게 주거나 잊어도 엔진이 채우며, 결과 줄에 `💧 수분 +45 (물) · -4 (시간·더위)`처럼 회복과 소모가 따로 표시됩니다 |
| 돈 | 무언가를 사면 엔진이 소지금에서 뺍니다. 돈이 모자라면 사지 못합니다. 번 돈·주운 돈·훔친 돈은 늘고(한 번에 최대 $600), 도둑맞거나 빼앗긴 돈·벌금은 줄어듭니다. 게임 마스터가 서술만 하고 반영을 빠뜨리면 서술된 금액을 자동으로 반영합니다 |

### 목적지로 가기

"가장 가까운 마을로 간다", "도시로 간다", "공관에 간다", "공항에 간다"처럼 목적지를 말하면, 엔진이 지금 있는 곳과
가진 수단으로 현실적으로 갈 수 있는 만큼만 이동시킵니다.

| 지금 있는 곳 | 수단 |
|---|---|
| 야생 | 걷기(지형별 속도, 밤에는 더 느림). 탈것이 있으면 운전. 마을로 이어지는 단서가 있으면 그쪽으로 |
| 마을 | 버스(요금을 냄). 돈이 없으면 히치하이킹을 시도 |
| 도시 | 150km가 넘으면 기차, 아니면 버스. 돈이 없으면 히치하이킹을 시도 |

- 곧장 갈 수 없는 곳은 먼저 갈 수 있는 곳부터 갑니다(야생 → 마을, 마을 → 도시 → 공항).
- 게임 초반(36시간)에는 마을까지만 갈 수 있습니다. 트럭·구조 헬기 같은 기회도 근처 마을까지만 데려다줍니다.
- 한 턴에 최대 10시간만 이동합니다. 더 걸리면 중간 지점에서 멈추고, "계속 간다"로 다음 턴에 이어 갑니다. 진행 중인 여정은 상태창에 표시됩니다.
- 야생에서 가장 가까운 마을까지는 지형에 따라 5~80km입니다(온대림이 가깝고 설원·사막이 멉니다).

- 이벤트나 서술에서 생긴 단서(엔진 소리, 연기, 불빛, 바퀴 자국, 송전탑, 강물, 길 표시, 가축 떼 등 13종)는 상태창 **CLUES**에 방향·거리와 함께 표시됩니다.

### 이벤트와 기회

| 항목 | 내용 |
|---|---|
| 돌발 이벤트 | 매 턴 위험 등급에 따라 20%(안전)·40%(주의)·60%(위험) 확률로 발생합니다. 그중 위험한 일의 비율은 25%·50%·75%입니다. 지금 상황 조건에 맞는 이벤트만 나옵니다 |
| 기회 | 매 턴 10% 확률로 찾아오고, 8턴 동안 없으면 반드시 옵니다. 다음 행동에서 받아들이지 않으면 사라지고(트럭 기사는 떠나고, 헬기는 날아갑니다), 장면과 그림에서도 지워집니다. 같은 종류의 기회는 6턴 동안 다시 오지 않습니다. 땅에 떨어진 보급 상자는 그곳을 떠날 때까지 남습니다. 기회의 낱말을 언급만 하는 것("트럭 기사에게 말을 건다")은 수락이 아니고, "탄다", "받아들인다", "따라간다"처럼 분명히 받아들여야 합니다. 지금 장면에서 일어날 수 있는 것만 나옵니다(실내에서는 지나가는 차량 등이 나오지 않음) |
| 기회의 대가 | 받아들이면 20~30% 확률로 나쁜 결과가 됩니다(강도, 사기, 상한 식량, 폭풍 등) |

### 자유 행동과 수배

| 항목 | 내용 |
|---|---|
| 범죄 의도 | 범죄로 처리할지는 엔진이 플레이어 입력으로 판정합니다. "빼앗는다", "훔친다", "기절시킨다", "불을 지른다", "뇌물을 준다", "위조한다", "주인 몰래 가져간다", "시동을 걸어 몰고 간다"처럼 직접 말하면 범죄, "트럭을 타려고 한다"처럼 모호하면 합법적인 행동(부탁, 흥정, 요금 지불)으로 봅니다. 단, 직전 추천 행동이나 최근 입력에서 같은 대상에 대한 범죄를 고려했다면("트럭을 훔칠까?") 모호한 입력도 범죄로 처리할 수 있습니다. 탈것은 빼앗거나 사거나 빌리겠다고 했을 때만 내 것이 됩니다 |
| 범죄의 결과 | 피해자는 등장인물과 '원한이 있는 사람'으로 기록되고 상태가 붙습니다(예: 트럭 기사 — 트럭을 빼앗김, 기절, 깨어나면 신고). 피해자는 돕지 않고 아무것도 주지 않으며, 그 사람의 제안(태워 주기 등)은 끝나고, 범죄는 게임 내내 유효한 사실로 남습니다 |
| 범죄의 여파 | 목격된 범죄 직후 현장에 있으면 다음 턴에 반드시 피해자·주민·경찰이 반응하고(이후 3턴 동안 50%), 기절시킨 피해자는 두어 시간 뒤 깨어납니다. 목격된 범죄를 저지른 마을·도시는 '범죄자로 알려진 곳'이 되어, 다시 오면 사람들이 알아보고 신고하며 도움을 주는 기회가 오지 않습니다. 훔친 물건은 장물로 기록되어 체포되면 압수되고, 훔친 탈것은 경찰의 눈에 띕니다. 이 여파는 매 턴 게임 마스터에게 전달됩니다 |
| 얻은 것의 출처 | 물건과 돈을 얻을 때는 출처(주움·삼·받음·일의 대가·훔침)를 함께 기록합니다. 훔친 것은 범죄 판정이 성공했을 때만, 산 것은 값을 낸 뒤에만 얻고, 원한이 있는 사람은 아무것도 주지 않습니다 |
| 시도의 보상 | 훔치기·협박처럼 이득이 걸린 시도는 판정 전에 얻을 돈과 물건을 정해 두고, 성공하면 엔진이 바로 소지금과 소지품에 넣습니다 |
| 시도 판정 | 결과가 불확실한 행동은 난이도별 기본 확률(쉬움 85% · 보통 60% · 어려움 35% · 매우 어려움 15%)에 보정(지침 -15%, 부상 -15%, 도구 사용 +15%, 밤에 몰래 +10%)을 더해 엔진이 판정합니다. 폭력 행동에 실패하면 체력이 깎입니다 |
| 탈것 | 시도에 성공한 턴에만 장면에 있던 승용차·트럭·오토바이·보트를 얻을 수 있습니다. 연료가 떨어지면 버려야 합니다 |
| 수배도 | 현실에서 범죄인 행동(폭행, 절도, 강도, 차량 절도, 침입, 사기, 협박, 밀입국, 무임승차)을 누군가 목격했을 때만 오릅니다. 기준값(성공 20, 실패 35) × 범죄 무게(0.4~1.3) × 목격자(없음 0 · 피해자만 0.6 · 주변 사람 1.0). 실패하면 아무도 없었어도 최소한 피해자에게는 들킨 것으로 봅니다 |
| 수배의 결과 | 시간이 지나거나 300km 이상 떠나면 내려갑니다. 수배 중이면 마을·도시에서 경찰이 다가오고, 50 이상이면 공항·항구에서 붙잡힐 수 있습니다(하루 구금, 벌금, 탈것·표 압수) |

## 동작 구조

```
플레이어 입력
   │
   ▼
[엔진] 턴 시작 ── ML 모델로 위험 등급 예측 ── 상황에 맞는 돌발 이벤트 추첨 ── 단서면 정체·방향·거리 확정
   │              └─ 가끔 대형 이벤트(기회): 실제 지도에서 목적지 결정
   ▼
[LLM] 현재 상태 + 확정된 사실 + 단서 + 화면에 보이는 것 + 이벤트 + 플레이어 행동을 받아 툴 호출을 요청
   │      시간·몸 상태: advance_time / update_status / update_inventory / pay
   │      이동:        go_to / travel / buy_ticket / follow_lead / accept_offer / seek_help
   │      판정:        attempt_action / acquire_vehicle / arrest
   │      이야기:      set_scene / add_character / add_lead / remember / reject_event / search_survival_guide
   ▼
[엔진] 툴 실행 (규칙 검증, 변화 폭 제한, 날씨·기후·지명 재조회, RAG 검색)
   │
   ▼
[LLM] 툴 결과를 보고 최종 서술 + 추천 행동 3개 생성 → 다른 언어가 섞였으면 한국어로 정리
   │
   ▼
[UI] 알림·대화창·상태창 갱신 → 자동 저장 → 장면이 바뀌었으면 새로 그리고 Vision으로 읽기,
                                          같은 장면의 낮밤·날씨 변화는 이전 그림을 편집
```

**설계 원칙: 숫자는 엔진이, 이야기는 LLM이.** LLM이 체력이나 돈을 마음대로 지어내지 못하도록 모든 수치는
`survival/state.py`의 규칙을 거쳐서만 바뀝니다. 성공 확률, 단서의 정체, 기회의 결과처럼 운이 걸린 것도
엔진이 정하고, LLM은 그 결과를 서술합니다.

### 낙하 지점을 정하는 방식

1. 위도 남위 50도~북위 68도 사이에서 지구 표면 넓이에 고르게 퍼지도록 좌표 40개를 뽑습니다(남극과 북극권 대부분 제외).
2. Open-Meteo 고도 API로 고도가 0m보다 높은 곳만 육지로 봅니다.
3. 서울에서 1,500km 이내는 뺍니다.
4. 남은 것 중 첫 번째를 고르고, 없으면 최대 4번 다시 뽑습니다. API가 실패하면 미리 정한 예비 좌표 5곳 중 하나로 떨어집니다.

넓은 땅(러시아, 캐나다, 사하라, 호주, 아마존 등)에 떨어질 확률이 높습니다.

## 사용한 외부 서비스

- [OpenAI API](https://platform.openai.com/) – 게임 마스터(`gpt-4o-mini`), 장면 이미지(`gpt-image-1-mini`), 임베딩(`text-embedding-3-small`). API 키가 필요합니다.
- [Open-Meteo](https://open-meteo.com/) – 현재 날씨, 시간별 예보, 고도, 과거 기후 기록. 키가 필요 없고 비상업적 용도는 무료입니다.
- [OpenStreetMap Nominatim](https://nominatim.org/) – 좌표 → 지명(화면용 한국어, 그림용 영어). 키가 필요 없고, 초당 1회 이하로 사용해야 해서 두 번 조회할 때 1초를 기다립니다.

## 한계와 개선 계획

- **위험도 모델은 합성 데이터로 학습했습니다.** 실제 조난 데이터가 아니라 생존 상식에 기반한 규칙에 노이즈를 섞어 만든 데이터라, 모델은 그 규칙을 근사할 뿐입니다(테스트 정확도 약 0.82). 플레이 기록을 모아 실제 사망·생존 결과로 다시 학습하는 것이 다음 목표입니다.
- **도시·공관 데이터는 게임용으로 단순화했습니다.** 좌표는 근삿값이고, 공관이 있다고 표시한 도시도 실제 현황과 다를 수 있습니다. 목록에 공관이 없는 나라에서는 가장 가까운 다른 나라의 공관으로 안내됩니다.
- **직접 이동하는 경로는 단순합니다.** 도보·히치하이킹·버스 등은 서울 방향 대권 경로를 따르며, 국경·비자·실제 도로망은 반영하지 않습니다.
- **기후 분류는 쾨펜 분류를 단순화한 것**이고 최근 1년 기록만 씁니다. 기록을 못 가져오면 위도와 현재 날씨로 추정합니다.
- **낙하 판정은 고도만 봅니다.** 해수면보다 낮은 땅(사해 주변 등)은 바다로 보아 제외되고, 해발이 높은 큰 호수 위에 떨어질 수 있습니다.
- **같은 건물 안의 다른 방은 구분하기 어렵습니다.** 이름이 겹치는 장소(예: '공관 영사과'와 '공관 회의실')는 같은 곳으로 보아 그림을 유지합니다. 그림 편집은 이미지 모델에 의존하므로 세부가 조금 달라질 수 있습니다.
- **일부는 게임 마스터(LLM)의 판단에 달려 있습니다.** 서술 중에 새로 꺼낸 단서의 등록, 금지어 목록에 없는 억지 행동의 판정, 그림 속 작은 대상의 인식은 완벽하지 않습니다.
- **오래된 세이브는** OpenAI 쪽 대화 기록이 만료될 수 있습니다. 이때는 최근 대화 6개를 줄거리로 넣어 새 대화로 이어갑니다.
- 계획 중: 음성 내레이션(TTS), 지도 표시, 플레이 기록 저장과 랭킹, 클러스터링(K-Means)을 이용한 기후대 분류.
